# Wintermute Desktop

Wintermute 的 Windows/macOS 桌面终端，使用 Electron、React 和 TypeScript。

## 连接 Agent

1. 启动 Wintermute 后端并启用 HTTP 接口。后端示例 `config/interfaces.example.json` 将 `http-desktop` 绑定到用户 `local` 的 `main` 会话，令牌由 `WINTERMUTE_HTTP_TOKEN` 提供。每台设备使用自己的终端 ID 和令牌，同一用户的终端可以绑定到同一个会话。
2. 打开侧栏底部的“设置”，默认进入“连接”。填写服务地址（本机默认为 `http://127.0.0.1:8080`）、终端 ID 和令牌，点击“验证并保存”。已保存的终端 ID、服务地址和连接状态也在这里查看。桌面端使用操作系统凭证加密保存令牌。
3. 应用直接打开对话。输入时按 Enter 换行，点击发送按钮或按 Ctrl + Enter（macOS 可用 ⌘ + Enter）发送，等待期间可继续补充。同一会话里来自其他设备的发言，以及定时提醒触发的 Agent 回复，也会自动显示。提醒触发的回复标记为“Wintermute · 通知回复”。

侧栏“设置 → 外观”提供跟随系统、浅色和深色，默认跟随系统。选择立即生效，保存在当前设备上，连接 Agent 前也可以设置。

拖动侧栏右侧的分割线可调整导航宽度，也可聚焦分割线后按左右方向键微调。标题栏左侧按钮可收起或展开导航，展开时恢复上次设置的宽度。点击标题栏右侧的「帮助」可查看软件简介和版本。

在“设置 → 接口密钥”查看后端模型密钥的用途、配置状态和脱敏尾号。选中需要更改的一项，输入新密钥并保存。共用同一项密钥的用途列在一起，保存后从下一次模型请求起生效。远程管理使用 HTTPS，本机调试可连接回环地址。后端须在对应 HTTP 终端配置中开启 `manage_api_keys`。

桌面端启动及运行期间会读取后端会话历史。滚动到顶部可加载更早的消息。后端清空后，桌面端下一次成功同步就会清除旧聊天。本机只保存待发送或待确认的请求与重试状态；发送超时后点击“重试发送”会复用原消息 ID。处理失败或中断时，可以点“重新提问”生成新请求。

## 远程命令

在“终端设置 → 设备工具”开启“命令行工具”。桌面端使用 HTTPS 或本机回环地址连接，以当前用户身份在用户主目录执行命令。Windows 提供已安装的 PowerShell 和 CMD，macOS 提供 `sh`。切换服务器、终端或令牌后，需要为新连接开启权限。

命令运行时间可设为 1–120 秒。标准输出和标准错误各返回最多 8 KiB。关闭开关会停止正在执行的命令。断线时客户端暂存结果并重试回传，进程意外退出前未保存结果的调用标为结果未知。打开“记忆”可查看调用记录。

## 接收设备通知

在侧栏打开「日程」，周历下方显示主 Agent 最近发给本终端的两条通知，点「显示全部」可在原处浏览更早的通知。展开一条通知可查看完整正文和附件，点击文件名选择本机保存位置。桌面端运行时约每 5 秒检查一次待收通知，窗口在前台时显示应用内横幅，在后台时使用系统通知。已过期的提醒可在收件箱查看。退出程序期间的通知会在下次启动后补收。

## 查看主 Agent 的日历

打开「日程」默认显示本周，日期下的小圆点表示当天有安排。使用左右箭头切换周，或点「展开月历」按月浏览。箭头之间的按钮在周历中显示「今天」或所选日期号，在月历中显示月份，点击即可回到今天。选中日期后，通知下方会按本机时间列出当天的触发时间、安排内容和状态。可在对话里让 Agent 新建、改期或取消安排。打开的日历会自动刷新。

## 浏览后端记忆

在「记忆 → 档案记录」浏览当前用户记忆目录里的全部 Markdown 文件，包括角色设定、用户画像、笔记及归档、变更日志。左侧目录可按文件名、标题或摘要筛选，右侧支持 Markdown 预览和原文切换，长文件分段显示。打开页面、切回窗口或手动刷新时会读取最新内容，页面可见时每分钟刷新。后端需配置 `events.memory.user_dirs`，并提供 `/v1/memory/tree` 和 `/v1/memory/file`。软删除目录 `.trash` 不展示。

「记忆 → 记录层」按记录原始发生时间倒序展示历史导入，支持按短信、通话、通讯录、Notion、录音列表和文档筛选。展开记录可查看来源、导入时间、整理状态及原文；列表和长原文分别分页加载。依赖后端 `/v1/records/items` 及 `/v1/records/items/{item_id}`。记录层独立于实时活动的合并线。

「记忆 → 对话历史」显示同一会话的对话。交流层、通知层、感知层和切片层分别记录各自收到的事件。展开感知记录可查看原始上报、附件和过滤结果。

「合并线」把感知和切片活动放在同一条时间轴上。AI 摘要按生成时刻排列，「写入上下文」按实际写入时刻排列。展开写入记录可以查看覆盖的活动时段和当时写给主 Agent 的原文。

## 桌面活动采集

连接终端后，在“终端设置 → 信息采集”分别启用需要的来源。

- **桌面活动。** 开启“采集桌面活动”后，客户端约每秒采样一次，未操作键鼠也会累计前台停留。应用切走或锁屏时上传该次完整停留，包含起止时间、采样估算时长和依次观察到的窗口标题变化。切回同一应用或解锁后开始新的停留。采样中断超过 45 秒（如系统休眠）时，上一段只计至最后一次采样。后端保留原始记录，规则阶段过滤 5 秒及以内的应用停留或标题。扣除短标题后，剩余不足 5 秒的活动也整条过滤。macOS 读取其他应用的窗口标题可能需要辅助功能和自动化权限。
- **自动截图。** 开启后，同一应用连续在前台停留满 10 分钟时，客户端对当前窗口截图一次。浏览器切换标签页、同一应用更换窗口或文档都会沿用计时，未操作键鼠不会中断。切到其他应用、锁屏或采样中断超过 45 秒会中断计时。截图暂存在本机，离开应用后随本次停留记录上传，离线时进入待发队列。可在记忆中查看截图和后端识别的文字。关闭截图会清理待传图片。macOS 需要录屏权限。

每台终端有独立待发队列，可在“信息采集”中重试或丢弃失败的上传。

## 开发

后端模块拆分不改变桌面端使用的 HTTP 协议。档案记录通过 `/v1/memory/tree` 列出文件，再通过 `/v1/memory/file?path=...` 读取正文的 `content` 字段。

使用 Node.js **24 LTS** 和 npm，依赖由 `package-lock.json` 锁定。

```sh
npm ci
npm run dev
```

`dev` 同时启动 Vite 与 Electron；关闭开发命令时两个进程一并结束。只预览网页可运行 `npm run dev:web`，访问 `http://127.0.0.1:5173`。端口固定，若已被占用会报错，避免 Electron 加载错误服务。

```sh
npm run lint
npm run build
npm start
```

以上命令使用 Electron 加载构建后的本地文件，不依赖开发服务器。

## 打包

```sh
npm run pack       # 当前系统的应用目录，输出 release/
npm run dist:win   # Windows NSIS 安装包，x64 + arm64
npm run dist:mac   # macOS DMG，Intel + Apple Silicon；在 macOS 上执行
```

Windows 本机预览程序位于 `release/win-unpacked/Wintermute.exe`，请保留整个目录。可以拖动窗口顶部的空白处移动窗口，使用系统窗口按钮最小化、最大化或关闭窗口。最小窗口尺寸为 860×680。macOS 保留原生菜单，关闭窗口后应用继续运行。Windows 关闭所有窗口时退出。

当前构建使用 Electron 默认应用图标及本地未签名配置。

## 结构

- `src/App.tsx`、`src/components/agent-settings.tsx`：会话、终端设置和主页。
- `src/components/memory-browser.tsx`：后端历史浏览、分页和附件保存入口。
- `src/components/ui/`：由 shadcn CLI 生成并纳入源码的 Button、Badge、Dialog。
- `src/index.css`、`src/App.css`：主题和响应式布局。
- `electron/main.cjs`、`electron/preload.cjs`：应用生命周期和类型受限的 IPC 接口。渲染器启用 sandbox/contextIsolation。
- `electron/agent.cjs`、`electron/activity.cjs`：主进程内的认证、持久收发、队列和系统活动采样。
- `electron-builder.yml`：Windows/macOS 打包目标。

构建资源使用相对路径，支持 Electron 的 `file://` 加载。生产页面使用 CSP，Vite 开发模式单独允许 React 热更新所需的内联脚本。

可继续通过 `npx shadcn@latest add <component>` 添加组件。参考：[shadcn Vite 配置](https://ui.shadcn.com/docs/installation/vite)、[Electron 上下文隔离](https://www.electronjs.org/docs/latest/tutorial/context-isolation)。
