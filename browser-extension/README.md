# 浏览器分享

在桌面端配置服务器，启用浏览器接入并复制配对码。Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`，开启开发者模式，选择“加载已解压的扩展程序”并选择本目录。点工具栏的 Wintermute 图标，粘贴配对码后点“验证配对”。扩展由本机桌面端代发，不用填写服务器令牌。

- 打开网页，点扩展的“分享当前网页”。桌面端将标题和域名记为一条文字切片。
- 选中一段网页正文，点右键“将选中文字分享到 Wintermute”。选区、网页标题和域名一并记录。最多接受 8000 个字符。跨站子框架中的选区使用子框架域名。
- 在目标网页的扩展弹窗中打开“自动记录此站点的前台页面”，并允许浏览器访问该站点。页面连续处于前台满 5 秒，且你切换标签页、导航到新页面或离开浏览器时，扩展才发送一条该页面的感知记录，包含离开时间、域名和最后看到的标题。同一页面修改标题会沿用本次停留。一个授权对应一种协议和一个主机名。在“桌面连接与站点”里可以逐项停止。
- 如桌面端暂时关闭，主动分享保留在本机扩展待发队列。打开桌面端后点“重试”，或点“清空”丢弃。自动页面观察不保留离线队列。更换配对码前先重试或清空待发分享。更换后需重新授权站点。

浏览器配对码只用于本机回环连接。关闭桌面端的浏览器接入后，该连接停止接收请求。页面内容只通过主动选区分享进入文字切片；自动观察不含页面正文、URL 路径、查询参数或片段。
